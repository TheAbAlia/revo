# Revo

Open-source AI reputation management for local businesses.

Revo helps businesses manage customer reviews, generate on-brand responses, and streamline reputation workflows.

## Status

Revo is currently in active development.

## Stack

* Next.js
* TypeScript
* Tailwind CSS
* PostgreSQL
* Drizzle ORM

## Development

```bash
pnpm install
pnpm dev
```

The application will be available at `localhost:3000`.
